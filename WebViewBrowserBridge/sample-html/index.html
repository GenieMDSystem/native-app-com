Native callback contract

Host these pages (or call the same payloads from your real web app). Android expects:

Type 1 — Waiting room

{
  "type": 1,
  "data": {
    "url": "https://example.com",
    "success": true,
    "openInBrowser": false
  }
}

Type 2 — Close WebView (return home)

{
  "type": 2,
  "data": { "success": true }
}

// or

{
  "type": 2,
  "data": { "close": true }
}

Type 3 — Open schedule link

{
  "type": 3,
  "data": {
    "url": "https://example.com/schedule/1",
    "success": true,
    "openInBrowser": true
  }
}

Send via: NativeApp.callback(JSON.stringify(payload))
